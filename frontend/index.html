Complete list of verified smart contract functions callable via RPC & MetaMask:

WRITE (TRANSACTION) bid() payable

Strict rules: msg.value > 0, msg.value >= startingPrice, and msg.value > highestBid.

WRITE (TRANSACTION) withdraw() returns (bool)

Outbid users withdraw their previous bids. Implements Pull-over-Push security.

WRITE (SELLER ONLY) auctionEnd() onlySeller

Transfers winning bid ETH to seller and finalizes auction state.

READ (FREE VIEW) startingPrice() returns (uint256)

Returns the minimum initial reserve price set by the seller.

READ (FREE VIEW) highestBid() returns (uint256)

Returns current winning bid in Wei.

READ (FREE VIEW) highestBidder() returns (address)

Returns Ethereum address of the highest bidder.

READ (FREE VIEW) pendingReturns(address) returns (uint256)

Returns the refundable ETH balance stored for any specific wallet.

READ (FREE VIEW) beneficiary() returns (address)

Returns seller address entitled to final payout.

READ (FREE VIEW) ended() returns (bool)

Boolean flag indicating whether the auction has concluded.
